# Massyf Community

Massyf is a node-based generator of photoreal rocks and cliffs for games and film.
Early access is coming soon at [massyf.com](https://massyf.com).

**This repository contains no source code.** It is the home of the Massyf community — use
[Discussions](https://github.com/renderville/massyf-community/discussions):

- **Bugs** — something broke or looks wrong. If Massyf offered to save a crash log, please attach it.
- **Q&A** — how do I…?
- **Ideas** — features and nodes you would like to see.
- **Show and tell** — rocks you made with Massyf.
- **Announcements** — releases and news.

You can write in English or Russian. Пишите на английском или русском.

Private matters (licenses, payments): support@massyf.com
